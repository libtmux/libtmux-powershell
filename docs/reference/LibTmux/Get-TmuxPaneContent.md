# Get-TmuxPaneContent

## SYNOPSIS

Capture rendered text from a pane.

## SYNTAX

### Range (Default)

```text
Get-TmuxPaneContent [-Pane] <Pane> [-StartLine <int>] [-EndLine <int>] [-Raw] [-EscapeSequences]
 [-EscapeNonPrintable] [-JoinWrappedLines] [-PreserveTrailingSpaces] [-TrimTrailingSpaces]
 [-AlternateScreen] [-Quiet] [-ModeScreen] [-Pending] [-Hyperlinks] [-LineNumbers] [-LineFlags]
```

### History

```text
Get-TmuxPaneContent [-Pane] <Pane> -History [-EndLine <int>] [-Raw] [-EscapeSequences]
 [-EscapeNonPrintable] [-JoinWrappedLines] [-PreserveTrailingSpaces] [-TrimTrailingSpaces]
 [-AlternateScreen] [-Quiet] [-ModeScreen] [-Pending] [-Hyperlinks] [-LineNumbers] [-LineFlags]
```

## ALIASES

None.

## DESCRIPTION

Read a native pane through the core capture request. By default each captured line is a separate string. Raw returns one string joined with LF, without inventing a trailing newline. History starts at the beginning of retained history; StartLine and EndLine select explicit bounds.

## EXAMPLES

### Example 1

Capture the first pane on the existing server identified by $SocketPath.

```powershell
LibTmux\New-TmuxServer -SocketPath $SocketPath | LibTmux\Get-TmuxPane | Select-Object -First 1 | LibTmux\Get-TmuxPaneContent -Raw
```

## NOTES

Capture is rendered terminal text, not a byte-exact output stream or proof that a shell command completed. History and StartLine are exclusive. PreserveTrailingSpaces and TrimTrailingSpaces cannot both be selected. Core capability checks govern flags on older tmux versions.
